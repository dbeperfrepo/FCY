    🚀 Getting Started

    1. Sign in — first-time setup creates your Administrator account (no default credentials); everyone after that signs in with their own email and password. New users can self-register via Create an account using the Administrator's shared sign-up code, or activate a pre-created account via a personal invite code.
    2. Monthly Report — official template with MoM change & cumulative performance; only applicable items shown, SN I–VI auto-regenerated.
    3. Period Report — Quarterly / Semi-Annual / Nine-Month / Annual consolidations with prior-period & prior-year comparisons (EURO/FX row now renders correctly).
    4. Reports — full statement (Plan / Actual / Variance); items without activity are hidden and numbering rebuilt.
    5. Sub-descriptions never print — main descriptions only.
    6. Pivot for analytics; Data Input for edits; exports carry the same filtered, renumbered layout.

    🔐 Authentication Notes

    Passwords are stored as salted PBKDF2-SHA256 hashes (150,000 iterations) generated with the browser's cryptographic RNG — never in plain text. Sessions honour “Remember me” and automatically expire (12h by default, 30 days when remembered). Repeated failed sign-ins are temporarily locked out. Create an account requires the shared Administrator sign-up code (found under Administrator ▸ Settings, and regenerable at any time); accounts created this way get the Editor role and are signed in automatically. The Administrator tab unlocks automatically for Administrator sessions, or with the demo credential below. Users added from the Administrator panel instead receive their own one-time invite code to activate their account and set their own password, and an Administrator can reset any user's password from Account Administration at any time — every reset is written to the audit trail.
    ⚠️ Deployment notice: this is a self-contained, client-side application — all accounts, sessions and the audit trail live in this browser's local storage only, with no backend server enforcing access control. There are no default or demo credentials; the first person to open the app creates the Administrator account, and every account after that is created by an Administrator and activated via a one-time invite code. Anyone with script-execution access to this page (e.g. browser DevTools) can still bypass the client-side checks, so this should not be the sole safeguard for sensitive data — a production deployment should ultimately authenticate against a real backend.

    📑 Report Types at a Glance

    📊 Dashboard — Plan vs Actual performance analytics, KPI summary and monthly drill-down charts.
    📑 Reports — Full FCY cashflow statement (Plan / Actual / Variance); applicable items only, auto-numbered.
    📆 Monthly Report — Official monthly template with this-month vs previous-month change and year-to-date cumulative performance.
    📅 Period Report — Quarterly / Semi-Annual / Nine-Month / Annual consolidations with prior-period & prior-year comparisons.
    🧮 Pivot Table Report — Drag-and-drop rows/columns/values with YoY, QoQ, MoM and Actual-vs-Plan comparisons; layouts can be saved as templates.
    🏦 MP&D Report — Official Monitoring, Planning & Development monthly template, with cumulative and prior-year comparisons.
    ✏️ Data Input — Full editable grid (Plan / Actual), including sub-details; all reports auto-filter from this data.
    🛡️ Administrator — Data backup/restore, reset, user & settings management, and audit trail (Administrator access only).

    💡 Tips & Shortcuts

    Switch the unit selector (Full / Thousands / Millions / Billions) on any report to change display scale without affecting underlying data.
    Use 📚 Export Multiple on Monthly, Period and MP&D tabs to batch-export several months or periods in one go.
    In the Pivot Builder, save a rows/columns/comparison layout with 💾 Save so it can be reopened later from Saved Report Templates.
    Print / PDF mirrors the exact on-screen filtered, renumbered layout — nothing extra is added or hidden on print.
