Add or Import FCY Data

Starting FY2026/27, all reporting is generated from files uploaded via Upload Data using the Download Template format — these become the single source of truth for that fiscal year. For fiscal years before 2026/27, use Manual Entry & Legacy Import.

Upload FY2026/27+ Monthly FCY Summary
Upload the filled-in "Monthly FCY Summary" workbook (.xlsx or .xlsb) — the same structure as the Download Template tab. The file's rows determine Beginning Balance, Inflows, Outflows, and the EURO translation line for every month; Actual vs Plan is detected automatically from the file's title row. Uploading replaces any data already on file for that fiscal year and type.

05 — Help

Help & Documentation

A quick reference for how the ledger, reports, and FY2026/27+ uploads work.

Getting around Glossary Reporting units Data sources Uploading data Printing & sign-off Troubleshooting FAQ
Getting around
What each tab is for.
  • Home — a snapshot of the current fiscal year: balances, recent activity, and quick links.
  • Dashboard — charts and KPIs for exploring inflows, outflows, and balances over time.
  • Reports — the four formal reports: Monthly Performance Report, FCY Line Item Report, FCY Periodic Report, and the MP&D Monthly Summary. Each can be printed, or exported to Excel or PDF.
  • Data Input / Import — where FCY data gets into the system: Upload Data and Download Template for FY2026/27 onward, and Manual Entry & Legacy Import for fiscal years before that.
  • Admin — team member management, visible to admin accounts only.
Glossary
Terms used throughout the ledger, reports, and uploads.
Beginning Balance
The FCY balance on hand at the start of a month. Carries forward automatically from the prior month's Ending Balance.
Inflow
Any FCY received during the month — export proceeds, borrowing, purchases from NBE or commercial banks, and similar line items.
Outflow
Any FCY paid out during the month — import payments, loan repayments, shipping and service charges, and similar line items.
FX Translation
The EURO-vs-USD conversion gain or loss for the month, applied on top of inflows and outflows.
Ending Balance
Beginning Balance + Inflows − Outflows + FX Translation. Becomes next month's Beginning Balance.
Actual vs Plan
"Actual" is what was recorded as having happened; "Plan" is the budgeted or forecast figure for the same period, used for comparison.
Fiscal Year (FY)
Runs July–June, written as e.g. "2025/26" for the year starting July 2025.
Periodic Report
A report aggregated over Quarter, Semi-Annual, Nine-Month, or Annual periods, rather than a single month.
Reporting units
All figures across every report — MP&D Summary, Monthly Performance Report, FCY Periodic Report, and FCY Line Item Report — are shown in USD million, converted automatically from the underlying source amounts. The full-precision amount is always stored underneath, so conversion never loses accuracy; only the display is scaled.
Fiscal year data sources
The system uses two different ways of getting data in, depending on the fiscal year:
  • Before FY2026/27 — data lives in the ledger already, or can be added via Single Entry or the legacy CSV/XLSX importer under Manual Entry & Legacy Import.
  • FY2026/27 onward — reports are generated only from files uploaded through Upload Data. That upload is the single source of truth for that fiscal year and type (Actual or Plan); uploading again replaces what's on file.
Uploading FY2026/27+ data — step by step
  1. Go to Data Input / Import → Download Template and download the Actual or Plan workbook.
  2. Fill in line-item descriptions and the 12 monthly figures. Don't move or rename rows/columns — the upload matches the file by position.
  3. Only the first month needs a Beginning Balance entered; every later month's opening balance carries forward automatically from the prior month's calculated closing balance.
  4. Go to Data Input / Import → Upload Data, choose the fiscal year, and select the completed file.
  5. Click Parse File to preview what will be imported, then Import This File to commit it.
Printing & sign-off
Every report includes the Development Bank of Ethiopia logo and a "Prepared by / Signature / Date" block in the bottom-left corner and a matching "Checked by / Signature / Date" block in the bottom-right corner, with today's date filled in automatically. These appear when you print, and in the Excel and PDF exports.
Troubleshooting
Common issues when uploading or reviewing data, and what they usually mean.
"No inflow or outflow line items were found" when parsing a file

The uploader reads the workbook by fixed row and column position. This usually means rows were inserted/deleted or a sheet was renamed. Start again from a fresh Download Template file and only type into the description and figure cells.

"Could not read this file" on upload

The file usually needs to be a genuine .xlsx or .xlsb saved from Excel (not a renamed .csv, and not a version protected or password-locked). Re-save it from the official template and try again.

The dashboard shows dashes or empty charts for a fiscal year

This means no Actual data is on file for that fiscal year yet — the Dashboard will show a banner confirming this. Upload a file, or pick a fiscal year that already has data using the selector.

Ending Balance doesn't match what I expected

Ending Balance is always calculated as Beginning + Inflows − Outflows + FX Translation for that month — it isn't a typed-in figure. Check the underlying line items in the Reports tab if a total looks off.

I forgot my password

Ask an admin to reset it for you from the Admin tab. Admins cannot see your existing password — only set a new temporary one.

Frequently asked questions
A report looks empty for a fiscal year — why?

For FY2026/27 onward, reports only show data that has been uploaded through Upload Data. Check that a file has been uploaded for that fiscal year and type (Actual/Plan).

Can I re-upload a file to correct a mistake?

Yes — uploading again for the same fiscal year and type replaces the previous data after a confirmation prompt.

Why can't I add FY2026/27 data with Single Entry?

Manual entry and the legacy importer are limited to fiscal years before 2026/27 to keep FY2026/27+ reporting consistent with the uploaded template as the single source of truth.

What's the difference between the Dashboard and the Reports tab?

The Dashboard is for exploring trends visually — KPIs, charts, and top contributors. The Reports tab produces the four formal, print-ready reports with the exact line-item structure and sign-off blocks used for official submission.

Can I export a report to Excel or PDF?

Yes — every report in the Reports tab has Excel and PDF export buttons, alongside a Print option. All three include the logo and sign-off blocks.

Who can see the Admin tab?

Only accounts with the admin role. Everyone else sees the same Home, Dashboard, Reports, and Data Input / Import tabs.
